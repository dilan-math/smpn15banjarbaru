Penyimpanan statis

CMS ini tidak menggunakan login, backend, atau database.

Edit data dari menu Berita, Galeri, atau Pengumuman. Data tersimpan sementara di localStorage browser. Klik Unduh JSON, lalu ganti file yang sesuai di folder data/ sebelum commit ke GitHub Pages. Dengan alur ini website tetap sepenuhnya kompatibel dengan hosting statis.

Perawatan data lokal

Hapus data sementara dari perangkat ini jika dibutuhkan.
